## 생각이 기술로, 기술이 경험으로.

바이트플로우는 소프트웨어를 개발하고, AI를 실제 업무에 연결합니다.  
웹·앱 서비스부터 업무 시스템, AI 적용까지. 필요한 기술을 하나의 흐름으로 만듭니다.

### 우리가 하는 일

| Software & Systems | AI & AX |
| :--- | :--- |
| 웹·앱 서비스 설계와 개발 | AI 도입 방향과 적용 가능성 검토 |
| 업무 시스템 구축과 데이터 연동 | 생성형 AI 서비스 개발 |
